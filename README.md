# Career-Ops Cloud Sandbox

Independent experiment running the original [Career-Ops](https://github.com/career-ops-hq/career-ops) on GitHub Actions. No DraftflowAI code, accounts, secrets, or database are shared. The first test is a read-only public job scanner using non-identifying role and region filters; no applications or emails are sent. Upstream software is MIT licensed. Results appear under Actions as a scan receipt.

This repository is public: do not commit resumes, contact details, credentials, or personal application reports.
