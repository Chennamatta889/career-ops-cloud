Questions or corrections?

We welcome reports about outdated opportunities, technical errors, accessibility issues and content corrections.

Private inquiries

For privacy, account-data, and other non-public inquiries, email mchennarao889@gmail.com. Include the general issue and the website page involved; never email passwords, one-time codes or access tokens.

Public bug reports

For a broken link or a non-sensitive technical issue, you can also open a GitHub issue. GitHub requires an account, and issues are public, so do not share personal information there.

For job applications

Career-Ops does not accept job applications on an employer's behalf. Apply through the employer's official vacancy page. If a listing disappears, the employer's careers site is the authoritative source.
